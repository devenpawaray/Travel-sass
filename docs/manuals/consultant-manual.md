# TRAVEL-SASS Consultant Manual (Sales Workflow)

## 🎯 Goal: Sell with Speed & Confidence
This platform is designed to help you generate error-free quotes in seconds while protecting the agency's profit margins.

## 1. Navigating the Inventory
The **Inventory** module contains all travel products (Hotels, Flights, etc.) that have been verified by the Secretary.
- Items are "Live" when they have a green status.
- You can see real-time availability and standard pricing here.

## 2. Generating a Quote
Go to the **Quotes** module to build a customer proposal.
1. Click **"New Quote"**.
2. Select an asset from the inventory.
3. The system will automatically calculate the price based on the **Business Rules** (e.g., 12% profit margin).
4. **Constraint**: You cannot set a price lower than the system-calculated minimum. This protects the agency from loss.

## 3. Managing Quote Status
- **Draft**: You are still editing.
- **Issued**: The quote has been sent to the customer. Pricing is now **Locked** for the duration specified in the rules.
- **Confirmed**: Customer has accepted. The financial snapshot is now immutable.

## 4. Handling Alerts
If a supplier changes a price after you have issued a quote, you will receive a **Yellow Alert**.
- Review the price change.
- The system will indicate if the margin is still protected.
- If not, you must re-issue the quote.

## ⚙️ Efficiency Tips
- Use the **Review Inbox** to check if your requested supplier data has been processed by the secretary.
- Monitor your **Activity Feed** to see if a customer has opened a quote (if tracking is enabled).
